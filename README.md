# LF 제휴 일자별 피벗 (경량)

본 대시보드([hyemjji87/kimhyemin](https://github.com/hyemjji87/kimhyemin))에서 내보낸
**(날짜 × 제휴사) 집계 JSON**만 읽어, 무거운 재집계 없이 **즉시** 피벗을 보여주는 경량 앱.

## 왜 별도 앱인가
본 대시보드는 `st.tabs`가 매 상호작용마다 모든 탭을 재실행 + 집계를 매번 재계산해서
제휴사 드롭다운 전환이 느렸다. 이 앱은 **미리 굳힌 집계 JSON**만 필터/피벗하므로 빠르다.

## 기능
- **날짜 × 제휴사**: 한 달을 골라 행=일 / 열=제휴사 매트릭스
- **제휴사 × 월**: 행=제휴사 / 열=월 — 여러 달 흐름을 한눈에
- **분석일 코멘트**: 특정 하루를 전년 동일자·동요일평균과 대조해 특이점 자동 코멘트
- 지표: UV / 인증자수 / 당월인증거래액 / 전체거래액 / 고객수(당월인증) / 객단가(당월인증)
- 순결제·총결제 토글, **전년비 %** 토글 (상승 ▼초록 / 하락 △빨강, 회사 컨벤션)

## 데이터 넣는 법
1. 본 대시보드 사이드바 → **「일자별 피벗 JSON (경량 앱용)」** 버튼으로 `daily_pivot_*.json` 내려받기
2. 이 앱 사이드바에서 그 파일 업로드 → 즉시 피벗
   - (선택) `data/daily_pivot.json`으로 커밋해두면 업로드 없이 자동 로드

## 개인정보
JSON에는 **집계 수치만** 담긴다(고객수는 nunique 개수만). 원본 행·고객번호는 포함하지 않아
퍼블릭 배포에 안전하다. 생성 로직: 본 대시보드 `daily_pivot_export.py`.
